# Changelog

## 1.0.3 — review package

Changes relative to 1.0.2. Datasets and images are unchanged (regenerated byte-for-byte by
`build_repository.py`).

* **PW13**: the test image is now selected deterministically (`sorted(...)[0]` = `test_000.png`).
  Previously `next(glob(...))` returned a file whose order depended on the operating system, so the
  number of contours could differ between machines.
* **PW08**: prints all thresholds of Table 6 (τ = 0.3, 0.5, 0.6, 0.7, 0.8) with false alarms and missed
  risk events, plus average precision and ROC AUC.
* **PW11**: prints RMSE and the two same-horizon baselines discussed in Section 4.2 (12-h hold-last value,
  24-h seasonal naive).
* **requirements.txt**: `scipy==1.14.1` pinned — with an unpinned recent SciPy, the pinned
  statsmodels 0.14.4 fails in PW11. Ultralytics and TensorFlow moved to the optional
  `requirements-gpu.txt`, because they are not needed for PW01–PW15 on CPU and TensorFlow 2.18 does not
  install on Python 3.13. Ultralytics pinned to 8.4.155, the version recorded in the S1 checkpoint.
* **Assessment blueprint**: column `focus` added, matching Table A2.
* **Added**: Supplementary Files S1 and S2, `verify_reported_values.py`, this changelog, an extended README.
* **Removed** from the package: internal drafting notes not related to the course materials.
